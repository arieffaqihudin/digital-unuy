# Data Catalog: Digital UNUY — Website & Digital Service Portal

**Status:** Draft · **Version:** 0.1 · **Source:** `docs/IMPLEMENTATION_PLAN.md` §7 / `docs/PRD.md` §10 · **DB:** MongoDB + Mongoose 9

## 1. Conventions

- Collections are Mongoose pluralized model names (e.g. `ServiceRequest` → `servicerequests`).
- Primary key: `_id` (`ObjectId`, generated by Mongoose unless stated).
- Timestamps: `createdAt`, `updatedAt` (`Date`, auto).
- Cross-collection references are `ObjectId` refs without database-level foreign keys; integrity is enforced in application code.
- `passwordHash` uses `select: false`.
- TTL indexes are used only for `sessions` and `activationtokens`.
- No soft-delete column; documents use `published`/`archived`, team members use `published`, users use `active`.
